📦 Scarica il progetto completo

Tutti i file pronti per girare sul tuo PC

⬇ Download ZIP (~2 MB)
Dopo aver scaricato: estrai, doppio-click su start.bat (Windows) o ./start.sh (Mac/Linux)

📋 Come usare lo Studio

1. Apri lo Studio
2. Tab Sprite → naviga 130 sprite + gruppi autotiling + custom
3. Tab Mappe → scegli "tutorial-1-firepit" dalle mappe del progetto → vedi il firepit piazzato → "Test nel gioco"
4. Tab Asset & Gioca → "✨ AI Sprite Generator" → genera nuove sprite → "Le mie sprite salvate"

🔥 Firepit già piazzato

Il progetto include già una custom class EntityWallFirepit (extends EntityWall) generata con AI, piazzata nella mappa tutorial-1-firepit alla cella (5, 13).

Per giocarla: apri studio-play.html → il bridge carica firepit + mappa nel motore vero → giocchi con WASD/frecce.
