🔧 How to Reproduce

Step 1: Open Studio → Asset tab → "✨ AI Sprite Generator v3" → Category: "🧑 Character Actions" → Template: "Walk Down — Rest" → Click "✨ Genera" (no reference yet)
Step 2: After generation → Click "↻ Set Reference" (the first pose becomes the reference for all subsequent poses)
Step 3: Template: "Walk Down — Left Leg Forward" → Click "✨ Genera" (uses reference via edit() for consistency)
Step 4: Repeat for all 15 poses (each uses the same reference → same character, different pose only)
Step 5: After all poses → Click "💾 Save in library" to save the prompt + reference for future reuse
Step 6: Download each pose with "⬇ PNG" → Use Frame Editor to assemble into final sheets

Total generation time: ~52s (reference) + 15 × ~14s (poses) = ~4.5 minutes
